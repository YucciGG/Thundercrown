# Thundercrown: A Skyrim Modlist
![Thundercrown](/Header.png)

## Introduction to Thundercrown
Thundercrown is a vanilla+ style list for Skyrim, meant to bring the game to modern standards whilst keeping the magic that made the game popular in the first place. 

Nexusmods: [Thundercrown](https://www.nexusmods.com/skyrimspecialedition/mods/179830)

## Requirements

Thundercrown comes with the latest nexus release of Community Shaders, including a full PBR overhaul. 
To get an idea of how the list performs I've been able to run the list at a stable 60fps (locked) without any upscaling or frame generation. 

#### My specs: 
- GPU: RTX 4070 Ti
- CPU: Ryzen 9 5950x
- RAM: 32GB 3600mhz
- SSD: M.2 NVMe drive

My specs are fairly high end, but again the mentioned performance was at a native resolution at a locked 60fps. With DLSS/FSR you should be fine with a weaker GPU. I don't have a minimum specs section because it would be hard to calculate that without any data. If you try the list, please report any performance issues!
